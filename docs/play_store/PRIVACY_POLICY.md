# Privacy Policy

Pani Puri Simulator is an offline-first game.

- **Data collected:** No data is collected by the developer. The game stores
  settings and save data locally on your device.
- **Save data:** `user://panipuri_save.json`, `user://settings.cfg`, and offline
  backups (`user://cloud_backup.json`, `user://leaderboards.json`). These stay
  on your device.
- **Cloud save:** Offline backup + shareable save codes are included. If a Play
  Games plugin is enabled in a future build, saves/leaderboards would sync
  through your Google account under Google's terms; no developer-owned server is
  required.
- **No tracking:** No analytics, no ads, no third-party trackers.
- **No personal models:** User-supplied characters are anonymised as
  `Customer 1, 2…`.
- **Voice lines:** Pre-generated audio files are bundled; no speech is sent to a
  server at runtime. Eleven Labs is used only at build time; no API key ships.

Contact: open an issue on the project's GitHub repository.
