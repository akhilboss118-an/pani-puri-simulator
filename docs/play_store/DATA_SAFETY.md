# Play Data Safety (draft answers)

- **Does your app collect or share user data?** No.
- **Is all data encrypted in transit?** Not applicable (offline); any future Play
  Games sync uses Google's TLS.
- **Can users request deletion?** Yes — delete the app; save files are removed.
- **Data types:** None collected by the developer. Local-only files: settings,
  save, backup, leaderboard. No location, contacts, photos, payment, or device ID.
- **Account:** Not required. Optional future Play Games account only if the
  plugin is added.
